# UAFix Player

Застосунок для перегляду фільмів, серіалів, мультфільмів, аніме й дорам з українською
озвучкою з каталогу [uafix.net](https://uafix.net) — без браузера й реклами.
Працює на **Windows, macOS, Android-телефонах і Android TV**.

**[⬇ Завантажити останню версію](https://github.com/minkoroman/uafix-player/releases/latest)**

> Неофіційний некомерційний застосунок: відео не зберігає й не розповсюджує — див.
> [застереження](#застереження).

## Можливості

### Каталог
- **Головна** — банер із новинками, «Продовжити перегляд», «Нові серії в обраному» й розділи
  (серіали, фільми, мультфільми, аніме, дорами, добірки за роками).
- **Чіткі офіційні кадри** — картки, банер і сторінка фільму беруть широкі кадри з
  [TMDB](https://www.themoviedb.org) замість маленьких картинок сайту з написами.
- **Сітка або список** — вигляд розділів можна перемкнути, а вигляд за замовчуванням обрати в
  налаштуваннях; нескінченна прокрутка й фільтр за жанрами.
- **Пошук** з історією: нещодавні запити під полем пошуку (на TV — у вікні пошуку).
- **Фільтри в розділах** — сортування (перегляди, рейтинг, дата), жанр, рік, країна, студія
  й тематичні добірки.
- **Обране** — з позначкою «Нова серія», коли в серіалі вийшла нова.
- **Історія переглядів** — усе переглянуте, разом із завершеним і місцем, де зупинились.

### Сторінка фільму чи серіалу
- Рейтинг IMDb, рік, тривалість, вікове обмеження, країна, жанри, опис.
- **Актори з фото** — натисніть: біографія й відомі роботи, а з них — пошук на сайті.
- Доступні озвучки (українська, багатоголоса, студії, оригінал із субтитрами).
- Сезони й серії: переглянуті — з позначкою ✓, розпочаті — зі смужкою прогресу.
- «Продовжити» — з тієї ж серії, хвилини й озвучки; «Дивитись спочатку»; трейлер.

### Плеєр
- Вбудований плеєр (libmpv): якість 1080p / 720p / 480p, масштаб (вписати / заповнити /
  розтягнути), озвучка й субтитри — у вікні вибору по центру.
- **Наступна серія сама** — картка наприкінці серії; попередня позначається переглянутою.
- **Пропуск заставки UAFLIX** (16 с) — відео одразу з початку фільму чи серії.
- Підсилення гучності, плашка гучності (стрілки ↑/↓ на комп'ютері), запам'ятовування
  субтитрів і озвучки.
- **Комп'ютер:**
  - повний екран — кнопкою, подвійним кліком чи Esc для виходу;
  - **міні-плеєр**: вікно на чверть екрана вгорі праворуч, поверх інших програм, точно під
    картинку без чорних смуг; перетягується за будь-яке місце; кнопка «Сховати за край»
    ховає його за край екрана (клік по смужці — назад); хрестик закриває відео й згортає
    застосунок; «Розгорнути» повертає як було — у вікно чи повний екран.
- **Телефон:** повний екран при повороті, плаваюче вікно (картинка в картинці) при виході на
  головний екран.
- **Android TV:** таймер сну, перемотка з пульта (що довше тримати — то більший крок),
  медіа-клавіші пульта.

### Трансляція на телевізор
- **Chromecast / Google TV / Android TV** — телевізор сам грає відео, телефон чи комп'ютер
  лише керує (пауза, перемотка, «Дивитись тут»).
- **DLNA (бета)** — Hisense VIDAA, Samsung, LG та інші; якщо телевізор не вміє відкрити
  потік напряму, застосунок передає йому відео сам.
- **AirPlay (бета)** — зі спарюванням за PIN-кодом з екрана телевізора (лише один раз).

### Синхронізація між пристроями
- Історія переглядів (де зупинились, які серії переглянуто) і обране — спільні для всіх
  ваших пристроїв за кодом синхронізації: «Налаштування → Історія і синхронізація».
  Зручно: код показати на телевізорі, а ввести на телефоні.

### Android TV
- Окрема збірка «UAFix TV» — з'являється в меню телевізора, ставиться поруч зі звичайною.
- Усе керується пультом: чітка рамка фокуса, бічне меню розділів, швидкий перехід на меню й
  пошук стрілками вліво/вправо, «Назад» — на крок назад (без випадкового виходу).
- Плеєр на весь екран із власною панеллю: перемотка, ⏮ ⏭, озвучка, субтитри, якість.

### Оформлення й налаштування
- Темна й світла теми (перемикаються одразу, без перезапуску).
- **Іконка застосунку на вибір** — класична, котушка, маска чи блискавка.
- Налаштування відтворення: субтитри, гучність, якість і масштаб за замовчуванням,
  автоповорот на весь екран (телефон).
- Українська мова інтерфейсу.

### Оновлення
- Застосунок сам перевіряє нові версії й оновлюється в один клік: завантажує файл саме для
  вашого пристрою, встановлює й перезапускається; після оновлення показує «Що нового».
- На комп'ютері — **дзвіночок** біля пошуку: помаранчева крапка, коли вийшла нова версія.
- «Повідомити про проблему» — напряму автору, з версією й пристроєм.

## Встановлення

На сторінці **[останнього релізу](https://github.com/minkoroman/uafix-player/releases/latest)**:

| Пристрій | Файл |
|---|---|
| Windows | `UAFix-Player-Windows.exe` (запускається без встановлення) |
| macOS | `UAFix-Player-macOS.zip` → перетягніть `UAFix Player.app` у «Програми» |
| Android-телефон | `UAFix-Player-Android-arm64.apk` |
| Android TV / приставка | `UAFix-Player-AndroidTV-armv7.apk` (працює й на 64-бітних) |

Збірки не підписані сертифікатом Apple чи Microsoft:
- **macOS** — перший запуск: правий клік на застосунку → «Відкрити»;
- **Windows** — якщо SmartScreen попередить: «Детальніше» → «Виконати однаково»;
- **Android** — дозволити встановлення з невідомих джерел.

Далі застосунок оновлюється сам.

## Для розробників

Python + [Flet](https://flet.dev) 1.0 (Flutter):

- `core.py` — мережа й розбір сторінок сайту: каталог, інфо про тайтл, сезони/серії/джерела, озвучки
- `main.py` — інтерфейс: головна, розділи, сторінка тайтлу, плеєр, налаштування, TV-режим
- `ui.py` — палітра, анімації, спільні компоненти
- `tmdb.py` — офіційні кадри з TMDB · `cast.py`, `dlna.py`, `airplay.py`, `hap.py` — трансляція
- `sync.py` + `sync_worker/` — синхронізація (Cloudflare Worker) · `updater.py` — оновлення
- `screen.py` — робоча область екрана для міні-плеєра

### Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install flet==1.0.4 flet-video==1.0.4 requests beautifulsoup4 pychromecast zeroconf==0.39.4
.venv/bin/python main.py          # TV-режим: UAFIX_TV=1 .venv/bin/python main.py
```

Ключ TMDB (необов'язково) — у файлі `~/.uafix_tmdb_token`; без нього — картинки сайту.

### Збірка й випуск

Збирає GitHub Actions ([build.yml](.github/workflows/build.yml)): macOS, Windows (портативний
`.exe`), Android (`.apk` arm64) і Android TV (`.apk` armv7), шаблон із 90/120 Гц.

1. Додайте зверху в [CHANGELOG.md](CHANGELOG.md) розділ `## x.y.z` — він стане описом релізу
   й вікном «Що нового».
2. Змініть `version` у `pyproject.toml`, закомітьте.
3. `git tag -a vx.y.z -m x.y.z && git push origin main vx.y.z`

Секрети репозиторію: ключ підпису Android (`ANDROID_KEYSTORE_B64` / `ANDROID_KEYSTORE_PASSWORD`
— **не втрачайте**: без нього Android не поставить оновлення поверх старої версії),
`TMDB_TOKEN`, `FEEDBACK_BOT_TOKEN` / `FEEDBACK_CHAT_ID`.
Якщо Mac-сервер GitHub довго недоступний — ручний запуск workflow з `platforms=macos`.

### Обмеження

- Вміст і потоки належать сайту uafix.net; якщо сайт змінить розмітку чи ввімкне захист,
  застосунку знадобиться оновлення.
- Трансляція DLNA й AirPlay — бета: не кожен телевізор приймає відео за посиланням.
